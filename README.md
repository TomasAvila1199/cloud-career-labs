# Cloud Career Labs

Hands-on path from enterprise and industrial IT infrastructure
to AWS Cloud, DevOps, DevSecOps, Cloud Security and OT/ICS Security.

## Learning path
1. Linux and networking
2. Python for automation
3. AWS and cloud architecture
4. Terraform / Infrastructure as Code
5. Docker and CI/CD
6. Kubernetes
7. DevSecOps and Cloud Security
8. OT/ICS Security

## Labs
- Linux: permissions, service troubleshooting, networking, health report
- Python: system inventory
- AWS: secure cloud foundation
- Terraform: repeatable infrastructure
- Docker/GitHub Actions: delivery pipeline
- Kubernetes: deployment and troubleshooting
- DevSecOps: security checks
- OT/ICS: fictional architecture

All labs use fictional data. No employer or customer information belongs here.
